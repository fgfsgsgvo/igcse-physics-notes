# P6.2 Q4 设计实验（7 分，固定框架 MP1–MP7）★★★

## 官方评分框架（**逐字**）

**最新版（w25 / m25 / s25 / m24 起）** —— `0625_w25_ms_62.txt` Q4 原文：

```
4   variable
    MP1   valid variable which may affect h stated
    apparatus
    MP2   ruler/measuring tape and additional apparatus to measure the independent variable
          (if not height of release or diameter of ball)
    method
    MP3   measure the independent variable and release the ball
    MP4   measure h and repeat for a new value of independent variable
    control variable
    MP5   any significant variable appropriate to the independent variable
    table
    MP6   columns with units, for independent variable and dependent variable
    conclusion
    MP7   compare readings in the table to see if/how/whether a change in the variable produces a
          change in h OR plot a (line) graph with axes specified
```

**旧版"附加点"式（s20–s23）** —— 第 7 分是一个自由选项：

```
MP7  additional point (one from):
     at least 5 sets of data taken,
     repeat each measurement and take average,
     2nd valid control variable stated,
     repeat for different resistor and compare pattern
     preliminary experiment to determine suitable range for independent variable
     measure air speed at same point each time
```

**2025 年的 MP7 两种形式**
- `0625_s25_ms_63.txt`：`at least 5 sets of data taken` · `repeat for each value of independent variable AND take average`
- `0625_s25_ms_62.txt`：`second control variable stated` · `at least five sets of data taken` · `repeat each measurement AND take an average` · `evidence of rate formula used`

## 🔧 Q4 七步答题模板（**照抄这个骨架**）

```
【第 1 步 · MP1 — 自变量】
   明确写出你要改变的那个量：
   "The independent variable is the initial temperature of the hot water."

【第 2 步 · MP2 — 器材】
   写出【测自变量】需要的器材 + 【测因变量】需要的器材：
   "Additional apparatus: a stopwatch/timer, a thermometer, a measuring cylinder."

【第 3 步 · MP3 — 方法（测量）】
   怎么写：先调自变量，再测因变量
   "Heat the water to a known temperature, then time the water cooling for five minutes
    and measure the final temperature of the water."

【第 4 步 · MP4 — 重复（换新的自变量值）】
   "Repeat for a new value of the initial temperature."     ← 必须点明"换了自变量"

【第 5 步 · MP5 — 控制变量】
   "Control variables: the volume/mass of water, the time of cooling, the room temperature."
   ⚠️ 要写【具体】的量，不能写 "keep everything else the same"

【第 6 步 · MP6 — 表格】
   "A table with columns for initial temperature / °C and final temperature / °C."
   ⚠️ 列名 + 单位，单位用斜杠

【第 7 步 · MP7 — 结论】
   "Plot a graph of rate of cooling against initial temperature."
   或 "Compare the readings in the table to see if the initial temperature affects
       the rate of cooling."
```

> 官方原话（这是考官给的答案）：
> *"The most comprehensive approach for candidates was to **address each of the bullet points in the question in the order given in the question**."* `(0625_s25_er)`
> *"It is essential that candidates **use the bullet points as guidance** when producing their plan. Candidates that did this usually produced more complete responses."* `(0625_s25_er)`

## ⚠️ Q4 的 12 个死穴（**每一条都有考官原话**）

| # | 死穴 | 考官原文 |
|---|---|---|

# P6.3 变量（Variables）

## 三种变量

| 角色 | 定义 | MS 措辞 |
|---|---|---|
| **Independent 自变量** | 你**主动改变**的量 | *"valid variable which may affect h stated"* · *"identify variable under test"* · *"named factor"* |
| **Dependent 因变量** | 你**测量**的量 | *"measure independent variable / measure initial and final temperatures / measure time"* |
| **Control 控制变量** | **全程保持不变**的量 | *"any significant variable appropriate to the independent variable"* |

> ⚠️ **控制变量的定义陷阱**：
> *"Some candidates did not realise that **a controlled variable was one that remained the same throughout the experiment**."* `(0625_w21_er)`

> ⚠️ **考纲不要求背定义**：
> *"Candidates **will not be required to recall the specific definition** of these terms in the examinations."* —— 要会**用**，不用会背。

## 控制变量要**具体**（**这是关键**）

| ❌ 不给分 | ✅ 给分 |
|---|---|
| "keep everything else the same" | "the volume of water" |
| "keep it constant" | "the initial temperature of the water" |
| "the same conditions" | "the material and diameter of the wire" |

> 官方原话：*"Few candidates gained the available credit for stating the control variable in this investigation, namely that **the length of resistance wire between the crocodile clips should remain constant**."* `(0625_w22_er)`

## ★ 高频控制变量清单（**按情境背**）

| 情境 | 标准控制变量（MS 原文） |
|---|---|
| **电阻丝测电阻** | `constant diameter/radius/gauge of wire` · `material of wire / same wire / same type of wire` · `temperature of wire` |
| **水的冷却** | `same volume of water` · `initial temperature` · `room temperature` · `time (of cooling)` |
| **球滚动/落下** | `mass of ball if diameter is factor` · `height of release` · `diameter of ball` |
| **浸入式加热器加热** | `volume of water if current is the independent variable` |
| **灯 / 太阳能电池板** | `distance of lamp from solar panel` · `height of lamp/height of solar panel` · `keep axis of solar panel and line of lamp perpendicular` |
| **风扇 / 涡轮** | `speed of fan (if distance/angle varied) or distance/angle between fan and turbine (if fan speed varied)` · `height of fan/turbine` · `angle of air flow` |
| **条状物弯曲** | `width of strip if thickness is the factor` · `all strips to have same width/thickness/profile` |
| **棱镜折射** | `angle of ray from ray lamp`（入射角） |

> ⚠️ **冷却实验里 `time` 不是控制变量**：*"**Any reference to time was not credited.**"* `(0625_w22_er)`

## 第二个控制变量 = 额外一分

- `0625_m22_ms_62` MP7：`**2nd valid control variable stated**`
- `0625_m24_ms_62` MP7：`second valid control variable stated / at least 5 sets of data taken / repeat each measurement AND take the average`
- `0625_s25_ms_62` MP7：`second control variable stated / at least five sets of data taken / repeat each measurement AND take an average / evidence of rate formula used`

> 官方：*"**Credit was also given for a second possible variable to keep constant.** Room temperature, surface area of the water and avoidance of draughts were among the relevant suggestions."* `(0625_w23_er)`

## 控制变量的"配对陷阱"

> *"Of those candidates who realised that a constant voltage was needed, **many contradicted their answer by adding that the current should also be kept constant.**"* `(0625_s23_er)`

> ⚠️ **自变量和因变量不能同时当控制变量**（否则实验做不了）。

# P6.4 器材与读数

## ★ 核心读数规则（**考纲原文**）

> **Taking readings:** read to an accuracy of **one half of one of the smallest divisions** on the scale; interpolation to the nearest half division.

**操作解读**：如果温度计分度是 1 °C，你**最多**读到 **0.5 °C**。如果你写 `20.1 °C`，就是在声称自己没有的精度 —— **考官会点名**。

> *"Most candidates correctly read the thermometer with only **very few giving the reading as 20.1°C**."* `(0625_s25_er)`

## 各器材的预期精度

| 器材 | 规格 | Paper 6 应读到 | MS 证据 |
|---|---|---|---|
| **刻度尺（30 cm，mm）** | mm 分度 | **最近的 mm = 0.1 cm**；写成 `2.7 cm`、`14.0 cm` | `l = 6.9(cm) w = 2.5(cm) h = 3.0(cm) … **all to nearest mm**` |
| **印刷图上量长度** | — | 题目会指定小数位：`to the nearest millimetre` / `to the nearest 0.1 cm` | 题干原文 |
| **量筒（50/100/250 cm³）** | 等径 | 读**凹液面最低点**；**视线垂直**；量筒放在**水平面**上 | `read at bottom of meniscus OR ensure measuring cylinder is on horizontal surface` |
| **温度计（−10 ~ +110 °C，1 °C 分度）** | 1 °C | **整度或半度**。**不要写 20.1 °C** | 见上 |
| **秒表** | 0.1 s 或更好 | 0.1 s / 0.01 s（视显示位数） | `min sec 1/100th` |
| **电流表** | 满偏 1 A 或 1.5 A，精度 ≥ 0.05 A | 2 位小数（如 `0.135 / 0.14 (A)`） | `0.135 /0.14(A)` |
| **电压表** | 满偏 5 V，精度 ≥ 0.1 V | 1 位小数（如 `4.4(0) (V)`） | `4.4(0)(V)` |
| **托盘天平（≤500 g，精度 ≥0.1 g）** | 0.1 g | 读 **0.1 g**；**但题目说"to the nearest gram"时必须取整** | 见下方陷阱 |
| **力计（force meter）** | 量程 1.0–3.0 N | 0.1 或 0.2 N；**检查是否调零** | `forcemeter Q has zero error OR has not been set to 0 at start` |
| **量角器** | — | 角度 **±1° 或 ±2°**；**从法线量起**，不是从表面量 | `r 32° ±1°` |

## ⚠️ "to the nearest mm / gram" 陷阱（**高频误解**）

> *"Answers were expected to be given to the nearest millimetre, which was usually the case, except for the length of distance y. Distance y was exactly 2 centimetres long, so candidates were expected to record an answer of **2.0cm**. **Only a minority of candidates did so and most wrote 2cm.**"* `(0625_s22_er)`

> *"A sizeable minority of candidates did not understand what the phrase **`to the nearest gram'** meant and gave **63.9g or 63.92g** as their answer."* `(0625_w21_er)`
> *"Some candidates seemed unfamiliar with the expression `to the nearest gram' and wrote down the mass of the beaker as **208.3g**."* `(0625_s21_er)`

**结论**：
- **"to the nearest mm" = 精确到 0.1 cm，要写出那一位小数**（`2.0 cm` 不是 `2 cm`）
- **"to the nearest gram" = 取整到整数克**，`63.9 g` 是**错的**

## ⚠️ 不要伪造精度

> *"The stretched length of the spring, 5.6 cm, was nearly always measured correctly from the diagram in Fig. 1.3, and its value recorded to the nearest millimetre. **Answers given to 3 significant figures, e.g. 5.60 cm, were not accepted.**"* `(0625_s24_er)`

> *"Candidates should be advised that in estimation problems of this kind, **it is sufficient to supply an answer to the nearest 1, 5 or even 10cm³**."* `(0625_w21_er)`

## ★ 各情境的标准"准确读数"答案

| 情境 | MS 原文 |
|---|---|
| 读**竖直**刻度（温度计、量筒） | `line of sight perpendicular to scale` · `read scale perpendicularly / at eye level / at right angles` |
| 读温度计（**完整的 3 条**） | `view scale reading perpendicularly` · `wait until readings stops rising (at start)` · `avoid thermometer touching beaker` |
| 边读温度计边计时 | `read thermometer perpendicular to the scale/at eye level` · `hold the stopwatch close to the thermometer` · `thermometer not touching the sides/base of the beaker` · `stir the water before taking a reading` |
| **在准确时刻读数** | `have stop-watch and thermometer near each other` · `set a timer for every 30s` · `one student watch timer & another student read thermometer` |
| 读量筒（画图作答） | `diagram showing a clear line of sight drawn at right angles to measuring cylinder level with the top of its contents` |
| 读弹簧长度 | `reading viewed perpendicularly` · `ruler close to spring` · `use of set-square/short ruler to measure length of spring` · `use of set-square to check ruler is vertical` · `use of horizontal marker`（任意两条） |
| 量单摆长度 | `approximate centre of bob` · `rule positioned to enable measurement of d from bottom of clamp` · `perpendicular viewing of the rule` |
| 计时振荡 | `Use of **fiducial point** / counting from when pendulum passes the vertical / start counting from zero` · `use of set square or similar horizontal aid` |

## ⚠️★ "at eye level" 什么时候是**错的**（**考官专门点名**）

> *"Only a minority of candidates correctly stated that to obtain an accurate value for the scale reading at balance, it was necessary to **view the scale perpendicularly**. Many candidates stated that the scale should be viewed **at eye level**, but **this comment was inappropriate here as the scale was being viewed from above and not from the side**."* `(0625_w22_er)`

| 仪器朝向 | 正确说法 |
|---|---|
| 刻度**竖直**（温度计、量筒立在桌上） | `read perpendicular to the scale` / `at eye level` ✅ |
| 刻度**水平**（尺子平放在桌上、天平） | `**view perpendicularly from above**` —— 写 "at eye level" **❌ 不给分** |

## ★ 数字与单位的三条死规则

### ① 单位必须跟着数字

MS 规则（`0625_w25_ms_62`，"Units"）：
> - A numerically correct final answer **without a unit is awarded the final answer (A) mark if the unit is shown correctly in the candidate's working**.
> - A numerically correct answer with a **missing or incorrect unit is not awarded** the final answer (A) mark. C (B or M) marks are awarded from the candidate's working.
> - **Accept units with incorrect use of upper-case and lower-case symbols, e.g. pA for Pa.**
> - Unless the mark scheme for a specific question part states otherwise, the only permitted derived units are: `W → J/s or Nm/s`; `Pa → N/m²`; `momentum → Ns or kgm/s`; `impulse → Ns or kgm/s`; `J → Nm`. **NB J is not permitted as the unit for moments.**

### ② 有效数字

> **考纲 §5.6**：*significant figures of a calculated quantity = **same as the least number of s.f. in the raw data used***

> **2025 官方指引（`0625_w25_ms_62` M4）**：
> - Unless otherwise indicated in the mark scheme final answers expressed to **two or more significant figures** receive the final answer (A) mark if the candidate's answer rounds to the mark scheme answer.
> - A final answer expressed to **one significant figure** is only awarded the final answer (A) mark where the final answer is exact to one sig. fig.
> - A correct numerical answer, quoted with **fewer significant figures than required** by the mark scheme (even if in the working it has the required number), **is not awarded** the final answer (A) marks.

> **Rounding errors（`0625_w25_ms_61`）**：*"A rounding error in an answer should be penalised, but **only where it occurs within one of the first three figures. Beyond that it may be ignored.**"*

> ⚠️ **不准用分数**：*"**The use of fractions is not allowed.**"* `(0625_m24_er / s21_er)`
> ⚠️ **不准用循环小数符号**：*"A few candidates used the **recurring symbol** and so could not gain the credit available for consistency of significant figures."* `(0625_m24_er)`
> ⚠️ **一组数据位数要一致**：*"many sets of R values were expressed to an **inconsistent** number of significant figures."* `(0625_m21_er)`

### ③ 单位写作规范（**严格**）

> *"Only the unit **`s'** was allowed and the unit **`sec' for t was not accepted**. Similarly, only the unit **°C** was allowed. **`C' and `C°' were not accepted as units**…"* `(0625_w23_er)`

| ❌ 不接受 | ✅ 正确 |
|---|---|
| `sec` | **`s`** |
| `C`（表示摄氏度） | **`°C`** |
| `C°` | **`°C`** |
| `I`（当单位用） | **`A`** |
| `N`（当 1/P 的单位） | **`1/N` 或 `N⁻¹`** |
| `cm³ / g`、`Pa`、`M / V`（当比例 a/b 的单位） | **无量纲，不写单位** |
| 重量用 `g` | **`N`** |

> ⚠️ **导数单位必须自己推**：
> *"Fewer successfully worked out that the unit is **°C / s**."* `(0625_s23_er)`
> *"The incorrect **`N / mm'** was often written at the head of the extension column."* —— 伸长量的列名应是 `extension / mm`，不是 `N / mm`。

# P6.5 表格（Tables）

## ★ 核心规则（**考纲 §5.6 原文**）

> **Recording readings:** reflect the precision of the instrument in the number of decimal places and unit given; a measurement/calculated quantity must be accompanied by a correct unit; **each column headed with name or symbol AND unit, e.g. `time/s`** — the **solidus (/)** is to be used for separating quantity and unit in tables, graphs and charts; **units not in the body of the table**; repeat readings where appropriate; significant figures of a calculated quantity = same as the least number of s.f. in the raw data used; a ratio is expressed as `x:y`.

## 给分要求（MS 原文）

表格是 **1 分**，要求**列名同时有"量"和"单位"**（至少对自变量和因变量）：

> `**columns with units, for independent variable and dependent variable**`（`0625_w25_ms_62` MP6）
> `**MUST be appropriate for method** with: columns, with correct units, for independent and dependent variables; **any other quantity mentioned must have correct units**`（`0625_m24_ms_62` MP6）
> `table with columns for (material of) disc, time/temperature difference … **with units in the headings only**`（`0625_s22_ms_62` MP6）

## ★ 表头写法（**必背**）

| ✅ 正确 | ❌ 错误 |
|---|---|
| `time / s` | 表头只写 `s`；只写 `time`；把单位写进表格里 |
| `temperature / °C` | 每个数字后面都跟着 `°C` |
| `length / cm` | 表格里写 `cm` |
| `rate of cooling / °C per min` | `rate`（无单位） |
| `concentration / mol per dm³` | `concentration`（无单位） |
| `V / V`、`I / A`、`R / Ω` | 每格重复写单位 |

> 💡 官方版式：**斜杠两侧有空格** —— `m / s2`、`distance / m`

## ⚠️ 表格的 6 个死穴

| # | 死穴 | 考官原文 |
|---|---|---|
| 1 | **表头没有单位**（最高频） | *"Some did **not include the required units**."* `(0625_s22_er)`；*"Common errors were **not including units in the headings**, incorrect units, e.g. **weight in g and not N**."* `(0625_s21_er)` |
| 2 | **单位写在表格主体里** | *"A small number of candidates **wrote units in the body of table instead of, or in addition to, the heading**."* `(0625_w20_er)` |
| 3 | **把符号当单位/量** | *"Some candidates **confused the symbol with the unit**, for example heading a column **current/I**."* `(0625_w20_er)`；*"Other candidates just wrote **`ammeter reading' or `voltmeter reading'**. **These are not quantities**, and candidates needed to write **`current' and `voltage'** here."* `(0625_m25_er)` |
| 4 | **列的不是实际测量的量** | *"results table headings must contain the physical quantities that need to be **actually measured**… Many tables had a column for **rate of cooling**, but **not for the final temperature of the water**."* `(0625_s25_er)` |
| 5 | **表格与题目要求的数据不匹配** | *"**Some candidates drew a table showing just length and resistance, with no mention of current and voltage.**"* `(0625_m25_er)`；*"**Candidates needed to check that the table matched the data they were required to record.**"* `(0625_m24_er)` |
| 6 | **忘记补全表格列名** | *"a significant number appeared to have **missed the instruction to complete the column headings**."* `(0625_w23_er)` |

## ⚠️ 不要为了作图方便把数据取整

> *"Some candidates **rounded their correctly calculated extensions to the nearest whole number. This was presumably to make the graph plotting exercise which followed easier. This is bad practice and candidates should be discouraged from doing this.**"* `(0625_s23_er)`

## 重复读数与平均值

- **考纲**：`repeat readings where appropriate`
- **标准写法**：`repeat each measurement **and take average**`（几乎每季都是 MP7 的选项）
- **⚠️ 关键限制**：
  > *"Candidates should be reminded that statements such as `repeat the experiment' or `repeat and average' are **too vague to gain credit unless it is clear that these `repeats' are being carried out for each (or the same) value of the independent variable**."* `(0625_s25_er)`

  ✅ 合格写法：`repeat for each length and take average` / `repeat for each value of independent variable and take average`

## 读数个数

**标准下限是 5 组**：

> `**at least 5 sets of data taken**`（`0625_m20_ms_62` / `m22_ms_62` / `m24_ms_62` / `s25_ms_62` 的 MP7）
> `**At least 3 extra values (all < 90°) given**` + `**Range to spread over at least 30°**`（`0625_w25_ms_61` 3(e)）
> `at least three additional values; **all values quoted are more than 0 and up to 100cm**`（`0625_s24_ms_61`）
> *"**at least five different values are required for a graph to be plotted** and that all results should be repeated and then the average for each one taken."* `(0625_w21_er)`

> ⚠️ 常见错误：*"**different readings are required not the same value for u repeated several times**"* `(0625_w23_er)` —— 重复**不是**把同一个值测五遍。

# P6.7 误差来源与改进（Error Sources & Improvements）

## 术语（考纲 §5.5）

考纲列出了这些术语（来自 ASE《The Language of Measurement》）：**true value, measurement error, accuracy, precision, repeatability, reproducibility, validity of experimental design, range, anomaly, independent variable, dependent variable**。

> ⚠️ **考纲明确**：*"Candidates **will not be required to recall the specific definition** of these terms in the examinations."* —— **不用背定义，要会用**。

| 术语 | 含义 |
|---|---|
| **measurement error** | 测量值与真值之差 |
| **random error** | 围绕均值的离散 → **重复取平均可减小** |
| **systematic error** | 恒定的偏移（如零误差）→ **取平均不能减小**，必须修正 |
| **zero error** | 仪器使用前未指零 |
| **parallax error** | 斜视刻度造成的误差 → **视线垂直/平视** |

## ★★ 误差 → 改进 对照总表（**全部是 MS 原文**）

| 情境 | 误差 / 困难（MS 原文） | 改进（MS 原文） |
|---|---|---|
| **量筒** | `graduations on measuring cylinder too large` | `use smaller measuring cylinder` 或 `greater number of marbles` |

## ★ "误差来源 + 对应改进" 的格式（**两段式，必考**）

MS 固定结构：
> `**suitable source of inaccuracy:** e.g. graduations on measuring cylinder too large / **improvement matching source of inaccuracy:** e.g. use smaller measuring cylinder or greater number of marbles`（`0625_m23_ms_62` 1(d)）

> ⚠️ **改进必须与误差一一对应**。"Use a better ruler" 这种不匹配的答案**拿不到分**。

## ⚠️★★ 最大的坑：题目说 "done carefully" 时，**不能答"操作不仔细"**

> **`0625_m23_er`**：*"Most candidates offered an **unacceptable source of inaccuracy which was to do with poor practice rather than an inherent issue with the equipment or procedure**."*
> *"Most incorrect responses showed **poor practice**, such as not reading the meters accurately or attaching the crocodile clip to the wrong length, **ignoring the instruction in the question to `assume that the procedure has been done carefully'**."*

> **`0625_s21_er`**：*"Most candidates gave examples of **poor experimental technique, such as parallax error and not reading the ruler correctly, despite the wording of the question**."*
> *"**Few candidates realised that this question was not about poor experimental practice but about correct and precise experimental technique.**"*

> **`0625_m22_er`**：*"Very few correct suggestions of possible sources of inaccuracy… Most responses referred to **poor experimental practice** despite the question stating that the experiment was carried out carefully. **Mention of poor experimental practice, such as using thick lines, was not accepted.**"*

> **`0625_w22_er`**：*"**Very few candidates realised that this question required an answer relating to the large uncertainty there would be in their results.** Many just referred to accuracy which gained no credit."*

**🔧 规则**
```
题目写 "Assume that the experiment is carried out carefully."
→ 要答【器材/方法本身固有的局限】，不能答【人没做好】

✅ 可以答：仪器分度太大 / 器材不是完美圆柱 / 百分比不确定度大 /
          指针的读数只能到最小分度的一半 / 温度会散失 / 反应时间
❌ 不能答：读数读错了 / 视线歪了 / 线画粗了 / 没仔细看
```

> ⚠️ **不要答反方向的改进**：
> *"Occasionally, **suggestions did just the opposite of what was required, e.g. using a thicker lid or wrapping the beaker in insulation**."* `(0625_s23_er)`

## ★ 零误差（**最高频"答不出"的点**）

> *"**Very few candidates suggested that the force meter had not been zeroed.**"* `(0625_s25_er)`

> ⚠️ **每次看到"为什么结果不准/为什么两个学生结果不同"，先想"仪器有没有调零"。**

## "提高精度"类改进必须**具体**

> *"The most common errors were basic statements that multiple resistors are less accurate or that too much heat would be generated. **Very few candidates stated that a variable resistor gives a range of continuous data.**"* `(0625_w22_er)`
> *"**Simply stating that it could allow for more current values was not enough.**"* `(0625_w20_er)`

## ★ "为什么不同学生的结果不完全一样？"

固定 1 分题。标准答案集中在：
`reaction time` · `human judgement` · `difficulty in judging (a level / a focus / a colour)` · `room temperature variation` · `non-uniform apparatus`

# P6.8 "是否在实验误差范围内相等"（±10% 规则）★★

## ★ 考纲规则（**原文**）

> *"comment on and explain whether results are equal within the limits of experimental accuracy (**assumed to be ± 10% at this level of study**)"*

## 给分结构（**固定 2 分**）

```
statement matching results                                                              [1]
justification matching statement / within limits of experimental accuracy / owtte       [1]
```

**MS 措辞表**

| MS 措辞 | 来源 |
|---|---|
| `statement matching results / **justification matching statement (`within limits of experimental accuracy'/ within 10%/close together owtte)**` | `m25_ms_62` 3(d)(ii) |
| `statement matching results / within limits of experimental accuracy/owtte AND **supported by values from table**` | `s25_ms_63` 3(c)(ii); `m21_ms_62` 3(c)(ii) |
| `statement matching results / **values used seen**, and justification matching statement` | `s23_ms_63` 2(c)(ii) |
| `statement to match results — expect YES / explanation of idea of beyond limits… **if values are equal, it is sufficient to say just that the values are equal**` | `s23_ms_62` 3(e) |
| `statement to match results — expect NO / explanation … (e.g., **values not close (enough)/too far apart/> 10% difference**` | `w21_ms_62` 2(e); `w22_ms_62` 1(d) |
| `values are within the limits of experimental accuracy/error/uncertainty **or values (very) close/close enough/not (very) far apart/both round to the same number/approximately equal/within 5%**` | `s21_ms_62` 2(f) |

## ★★★ 考官给的算法（**金子，直接照抄**）

> `0625_s25_er`（0625/62 Q3(e)，逐字）：
> *"Candidates were asked to state whether their values of f1 in (c) and f2 in (d) could be considered to be equal within the limits of experimental accuracy, having been told that this is true if their values are within 10 per cent of each other. Many candidates were able to do so.
> **The easiest way to show this was to calculate the ratio of the smaller of the two values to the larger. If the value obtained was 0.9 (90%) or greater, then the quantities could be considered to be equal.**
> **Another equally acceptable method was to calculate the ratio of the difference between the two values to either of these values. If the answer obtained was 0.1 (10%) or less, then the quantities could be considered to be equal.**
> Other acceptable and novel methods of doing this were also seen and credited.
> **If both values of f recorded by candidates were equal, it was sufficient to state just that to obtain full credit.**"*

## ★★ 5% / 10% 双阈值规则（**2021–2022 报告中最完整的一段**）

> `0625_s22_er`（逐字）：
> *"Generally, if the values differ by **5 per cent or less, the expected answer is `yes, they are the same'**. If the values differ by **more than 10 per cent the expected answer is `no, they are different'**.
> **Between the values of 5 per cent and 10 per cent, either answer is acceptable if it is qualified by a phrase, such as `yes, they are close enough to be considered to be equal' or `no, they are too far apart to be considered to be equal'.**"*

> `0625_w22_er`（逐字）：
> *"Generally, if two values differ by **10 per cent or less, the expected answer is `yes, they are the same'**. If the values differ by **more than 10 per cent the expected answer is `no, they are different'**. **A calculation should be given to justify the statement made.**"*

> `0625_s23_er`（逐字）：
> *"**The idea of experimental tolerances, and whether two measured quantities are close enough to be considered equal, was not well understood by many candidates.** Generally, if the values differ by 10% or less, the expected answer is `yes, they are the same'."*

## 🔧 操作化总结（**可以直接背这张表**）

| 两值相对差 | 应作答 | 是否需附加措辞 |
|---|---|---|
| **≤ 5%** | **YES，"they are the same"** | 不必（给计算更好） |
| **5% – 10%** | **YES 或 NO 都可** | **必须**加限定词：`close enough to be considered equal` / `too far apart to be considered equal` |
| **> 10%** | **NO，"they are different"** | 不必 |

> **无论哪种，必须写出数值或算出差值百分比。**

## ★ 满分回答的三要素

```
① 与【自己的数据】相符的 statement（YES / NO）—— 不是与理论相符！
② 引用数值 或 算出差值/比值百分比
③ 出现 "within the limits of experimental accuracy"（或 within 10% / close enough）
```

## ⚠️ 学生错在哪（**考官原话**）

| 错误 | 考官原文 |
|---|---|
| **以为"只要不一样就不算相等"** | *"there were answers which stated that **any difference in values suggests that they cannot be considered as equal**."* `(0625_m24_er)` |
| **结论与自己数据矛盾** | *"Some candidates gave an answer that **contradicted their results**."* `(0625_w22_er)` |
| **用理论不用数据** | *"The statement needed to **match the results rather than the theory**."* `(0625_m21_er)` |
| **不引用数值** | *"others did **not show the values at all**"* `(0625_m23_er)`；*"**Credit could not be awarded if values were not used to support the argument.**"* `(0625_m21_er)` |
| **只写"成正比"没有数据** | *"**Responses simply stating that they are directly/inversely proportional also did not gain credit.**"* `(0625_s24_er)` |
| **抄题干** | *"Many candidates unnecessarily **repeated the words in the question**… A comparison of (RS + RL) with RC was required along with **a simple statement**."* `(0625_w21_er)` |
| **只给 statement 不给 justification** | *"Many candidates made a correct statement but **not all gave an appropriate justification**."* `(0625_s25_er)` |

# P6.9 高频实验情境专项

> 三大巨头：**① 冷却速率 cooling rate；② 米尺平衡 metre-rule balancing；③ 电路 V–I / 电阻 resistance。**
> 其次：**弹簧 spring、透镜 lens、密度 density、折射 refraction。**
> 这七个覆盖了 Paper 6 的绝大部分。

## ① 冷却速率（Cooling Rate）—— **Paper 6 第一大题**

**标准子问题**：补全表头（`s`、`°C`）→ 一个注意事项 → 画温度–时间图 → 算冷却速率 → 判断哪个杯保温好 + 用数值论证 → 说出一个控制变量。

**🔧 标准"注意事项"（3 选 1 即可）**
```
read scale perpendicularly           读数视线垂直
wait until reading stops rising      等读数不再上升（开始时）
stir before reading                  读数前搅拌
avoid thermometer touching beaker    温度计不要碰到杯壁
```

**🔧 冷却速率公式**
```
rate of cooling = decrease in temperature / time       单位 °C/min 或 °C/s
```

**🔧 保温判断模板**
```
"Beaker A cools more slowly / has the smaller temperature decrease.
 Therefore beaker A is the better insulator.
 The final temperature of A was __°C compared with __°C for B."
```

> ⚠️ **改进实验必须对【两个】beaker 同时改**：
> *"candidates often referred to a change to only one of the beakers rather than both, for example, 'wrap insulation around one of the beakers'."* `(0625_w20_er)`

> ⚠️ **读数时机的坑**：
> *"There were some candidates who started reading the thermometer too early – **before it had reached thermal equilibrium** with the water and therefore initial readings increased before decreasing. In a small number of cases, candidates **recorded the room temperature as their first temperature reading**."* `(0625_w20_er)`

> ⚠️ **结论只能用数据，不能用理论**：
> *"Only a simple statement giving a conclusion was required here. **Candidates should not use theory to arrive at a conclusion or to explain a conclusion. They needed to use the values in the results table.**"* `(0625_w20_er)`

> ⚠️ **单位缺失是高频失分**：
> *"Many candidates were able to complete this part successfully but those that did not **often omitted the units**."* `(0625_w20_er)`

## ② 米尺平衡（Metre-Rule Balancing）

**标准子问题**：画平衡点示意图 → "repeat and average" 或 "move the load back and forth" → 作图 → 读截距 → "为什么这个值只是近似值"。

**🔧 找平衡点的唯一认可技巧（MS 原文）**
> `**Repeat and average** OR **Move the load back and forth/slowly** (to establish the range within which the balance point resides or until best balance).`（`0625_w25_ms_61` 1(e)）

> 官方扩展版：*"only a small number recognised the technique of **achieving a position between the ruler just tilting one way and then just tilting the other way**."* `(0625_m24_er)`

**🔧 读平衡点刻度**
> ✅ `view the scale **perpendicularly**` / `view perpendicularly **from above**`
> ❌ `at eye level` —— **在水平尺子的语境下是错的**（尺子是俯视，不是侧视）

**🔧 找重心（无载荷平衡）**
> *"Candidates were expected to **describe balancing the ruler on the pivot with no loads and state that the balance point shows the position of the centre of mass**."* `(0625_w23_er)`

## ③ 电路 / 电阻（Circuits & Resistance）

**标准子问题**：读电流表/电压表 → 用 `R = V/I` 算 → 补全电路图（电流表串联、电压表并联）→ 作 R 对 l 图 → 求梯度 → 为什么加保护电阻。

**🔧 关键答案**
| 问题 | 答案 |
|---|---|
| 为什么加保护电阻？ | **`limits the current`（防止超过电流表满偏）** |
| 为什么要测多个长度？ | 画图 → **`anomalous results could be identified and ignored`** / 取平均 |
| 电阻丝误差来源？ | `uncertain connection point on crocodile clip` · `resistance wire not uniform` |
| 改进？ | `reduce e.m.f. of power supply` · `thinner resistance wire` · `additional series/protective resistor` |

> ⚠️ *"**Few candidates realised that the purpose was to limit the current from becoming too large.**"* `(0625_s25_er)`

> ⚠️ *"Far fewer candidates stated that **the resistance of the wire should be calculated for each pair of readings of V and I recorded**."* `(0625_w22_er)`

## ④ 弹簧（Spring / Extension）

> 标准答案：`suspend load from loop of thread` · `use of set-square to check ruler is vertical` · `reading viewed perpendicularly`

> ⚠️ 误差来源：`metre rule not uniform` · `test load not exactly 1.0N`

## ⑤ 透镜（Lens / Focal Length）

**🔧 关键答案**
| 问题 | 答案 |
|---|---|
| 像太小测不准？ | `use a larger object` / `graph paper on screen` / **`mark top and bottom of image and measure after`** |
| 手/尺挡住光？ | **`use a translucent screen and measure from the back`** / `fix grid to screen` |
| 如何精确对焦？ | **`move the lens slowly / backwards and forwards`** |
| 画像的标注 | **像必须"倒立 + 缩小"** |

> ⚠️★★ **对焦只能"移动透镜"**（2025 年误答率最高的一题）：
> *"**Very few candidates realised that in this experiment, since the distance between the screen and the illuminated object is fixed for each calculation of f, moving the screen and/or the illuminated object slowly or backwards and forwards to obtain a sharp focus was an inappropriate choice. The only acceptable answer here was to move the lens slowly or backwards and forwards.**"* `(0625_s25_er)`

> ⚠️ **"在暗室做"是无效答案**：
> *"A number of candidates again referred to ensuring that **the room was dark** rather than focussing on the technique of **moving the screen slowly and/or back and forth**."* `(0625_m24_er)`

> ⚠️ **画像时要体现"缩小"**：
> *"Most candidates drew a triangle which was **inverted**, but **far fewer made it obvious that the triangular image was diminished**. The inverted image drawn was often **the same size as the object, or in some cases larger**."* `(0625_s25_er)`

## ⑥ 密度（Density）

**🔧 三种测法**
| 对象 | 方法 |
|---|---|
| **规则固体** | 天平测质量；尺子测长宽高（**相乘，不是相加**） |
| **不规则固体** | 天平测质量；量筒**排水法**（`V = V₂ − V₁`） |
| **液体** | 空量筒质量 → 倒入后总质量（**差值**）；量筒读数 |

> ⚠️ 误差：`graduations on measuring cylinder too large` · `thread affects volume` · `clay may absorb water`

## ⑦ 折射（Refraction / Transparent Block）

> 标准答案：**法线画垂直（`normal neat and at 90°`）** · 针距 ≥ 5 cm · 角度从**法线**量起 · 细针细线

> ⚠️ 误差：`thickness of the light rays` · `difficult to judge the centre of the ray` · `difficult to align pins`

# ⚠️ 高频失分点汇总

| # | 陷阱 | 正确做法 |
|---|---|---|
| 1 | **背旧 mark scheme 的答案** | **每道题按本题情境作答**（考官连续 6 年点名） |
| 2 | 不写出自变量 | Q4 第一步就写 `The independent variable is …` |
| 3 | Q4 漏写"测自变量需要的器材" | 器材要**覆盖自变量和因变量** |
| 4 | 写 "repeat the experiment and take the average" | 太模糊；要写 **`repeat for each value of the independent variable`** |
| 5 | 控制变量写"keep everything else the same" | 要写**具体的量**（`volume of water`） |
| 6 | 控制变量写错反而扣分（CON） | 不确定就**少写**，写了错的会被判矛盾 |
| 7 | 把自变量和因变量同时当控制变量 | 实验会做不了 |
| 8 | 表格列名没有单位 | **`quantity / unit`** |
| 9 | 单位写在表格主体里 | **单位只在表头** |
| 10 | 列名写成 `current/I`（符号当单位） | 写 **`current / A`** |
| 11 | 列名写成 "ammeter reading" | 要写 **`current` / `voltage`** |
| 12 | 表头列的是推导量（rate of cooling） | 列**实际测量的量**（initial / final temperature） |
| 13 | 表格没 `(0,0)` 行 | 数据有 (0,0) 就要列 |
| 14 | 忘记补全题目给的表格列名 | 看清 `complete the column headings` |
| 15 | 把算出来的值取整以便作图 | **不准取整**（考官明确说 "bad practice"） |
| 16 | **作图坐标轴刻度用原始读数** | 用 **1、2、5** 的比例；否则作图分最多 1 分 |
| 17 | 作图尺度太窄 | 点要占**至少半个网格** |
| 18 | 轴画反 | 只丢 1 分，其余 3 分照给 |
| 19 | 漏标轴的量和单位 | `quantity / unit`，**轴名和单位都要** |
| 20 | 用大圆点/blob 描点 | 用 **`+` 或 `×` 或小圆圈** |
| 21 | 描点超出 ½ 小格 | 容差是 **±½ 小格** |
| 22 | **拟合线强行过原点** | 除非有理由，**不能强行过原点** |
| 23 | 拟合线"点到点连线" | 要**单条细线**，两边点数大致均匀 |
| 24 | 拟合线只连首尾两点 | **要把所有点都考虑进去** |
| 25 | 异常值不标注 | **要在图上圈出来** |
| 26 | 连续变量画柱状图 | 只能画**散点/折线图**（类别变量才可以画柱状图） |
| 27 | **求梯度不画三角形** | **必须在图上画大三角形** |
| 28 | 三角形太小 | 要覆盖**至少半个线段**（首末点之间） |
| 29 | 三角形画到轴外 | 要贴着线画 |
| 30 | 梯度不写单位 | 单位**由轴推出** |
| 31 | 读截距不延长线 | 要**延长到轴**再读 |
| 32 | 截距超出 ½ 小格 | 容差 **±½ 小格** |
| 33 | **温度计读成 20.1 °C** | 1 °C 分度只能读到 **0.5 °C** |
| 34 | 量筒不读凹液面最低点 | **`bottom of the meniscus`** |
| 35 | 量筒不放水平 | **`on a horizontal surface`** |
| 36 | 尺子读到 3 位有效数字（5.60 cm） | 只读到**最近的 mm**（`5.6 cm`） |
| 37 | 误解 "to the nearest mm" | = **精确到 0.1 cm**，要写 `2.0 cm` 不是 `2 cm` |

| 41 | 按比例画图不乘比例因子 | 除以比例 = 错（应**乘**） |
| 42 | "not full size" 题按图上量 | 要答**现实尺寸** |

# 🧠 一页纸速记

## 试卷结构

```
Paper 6 = 1 小时 / 40 分 / 4 题
        = 11 + 11 + 11 + 【7】     （m26 起：10 + 11 + 12 + 7）
Q4 永远是 7 分的"设计实验"题 = 全卷 17.5%
```

## ★★ Q4 七步骨架（MP1–MP7）

```
① 自变量 —— 明确写出 "The independent variable is …"
② 器材   —— 覆盖【测自变量】和【测因变量】
③ 方法   —— 先调自变量，再测因变量
④ 重复   —— "repeat for a new value of the independent variable"  ← 必须点明"换了自变量"
⑤ 控制变量 —— 写【具体】的量，不能写 "keep everything else same"
⑥ 表格   —— 列名 + 单位（斜杠），单位只放表头
⑦ 结论   —— "plot a graph of ___ against ___" 两个轴都写出来
```

## ★★ 作图 4 分分配

```
[1] 坐标轴：量和单位 + 方向正确
[1] 尺度：占满 ≥ ½ 网格（用 1、2、5 的比例）
[1] 描点：±½ 小格，用 + 或 ×（不用大圆点）
[1] 拟合线：单条细线，两边点数均匀，不强行过原点
```
> ⚠️ **用原始读数当等间距刻度 → 作图分最多只有 1 分**

## ★★ 求梯度（2 分）

```
[1] 图上画出三角形（覆盖 ≥ ½ 线段）
[1] 正确的计算方法 Δy/Δx
```
> ⚠️ **不画三角形 = 丢分**；梯度值通常给区间

## ★★ "是否在实验误差范围内相等"（2 分）

```
[1] statement 与【自己的数据】相符（YES / NO）
[1] justification：引用数值 + "within the limits of experimental accuracy"
```

| 相对差 | 答案 |
|---|---|
| **≤5%** | YES |
| **5%–10%** | YES 或 NO，**必须加限定词** |
| **>10%** | NO |

## ★ 表格

```
✅  time / s          temperature / °C      length / cm
❌  "s" 单写          "time" 无单位          单位写在数据格里
❌  current / I       "ammeter reading"
```

## ★ 读数精度速查

```
刻度尺        → 最近的 mm（0.1 cm）；"to the nearest mm" 要写 2.0 cm
温度计(1°C)  → 整度或半度；不要写 20.1 °C
量筒          → 凹液面最低点，视线垂直，放水平面上
电流表        → 2 位小数
电压表        → 1 位小数
天平          → 0.1 g；"to the nearest gram" 要取整
力计          → 检查是否调零！
量角器        → ±1° 或 ±2°，从【法线】量起
```

## ★ "准确读数"的标准答案

```
刻度竖直（温度计/量筒）→ read perpendicular to the scale / at eye level
刻度水平（尺子/天平） → view perpendicularly from an angle looking DOWN
                        （写 "at eye level" 是错的！）
```

## ★ 高频"误差 → 改进"配对

| 误差 | 改进 |
|---|---|
| 量筒分度太大 | 换更小的量筒 / 增加样品数 |
| 电流过大 | **加保护电阻（limits the current）** |
| 像太小测不准 | 用更大物体 / 屏上贴方格纸 / 先标出上下端再量 |
| 手或尺挡住光 | **用半透明屏，从背面看** |
| 对焦不准 | **缓慢来回移动透镜** |
| 大头针太粗 | **细针 + 细线 + 削尖铅笔 + 针距 ≥5 cm** |
| 力计读数不准 | **检查是否调零** |
| 计时反应时间 | **测多次取平均 / 用基准点计时** |

## ★ 三条铁律

```
① 引用数值 —— 任何结论/比较都要引用自己算出的数字
② 具体     —— 不写"要更仔细"、不写"keep everything the same"
③ 按题作答 —— 不背旧答案；题目说 "carefully" 就不能答"操作不仔细"
```
